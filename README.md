# Ferox

Ferox is my first implementation of an open source libary using the Rust Language.

Ferox aims to be an LLM provider gateway that will deliver Multi-provider AI inference support for 
upstream consumers.

## Development Roadmap 

- [ ] OpenAI Compatible Chat Completions endpoint 
    - [ ] handle reasoning injection into context array
    - [ ] handle reasoning effort being passed to inference provider 
- [ ] Basic Logging 
- [ ] Provider Configuration
- [ ] Open Telemtry and Advanced Logging
- [ ] Publish as cargo package
